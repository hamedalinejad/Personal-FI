# Live status vocabulary

Use **only**:

```text
SPEC_LOCKED
IMPLEMENTED
PARTIAL
BLOCKED
DEFERRED
CLOSED_HISTORICAL
```

Release acceptance:

```text
GOLDEN-GREEN
RECOVERY-GREEN
RELEASE-PROVEN
```

**Do not** treat these as synonyms: READY, DONE, GREEN, IMPLEMENTED, PROVEN.

Also: `READY TO IMPLEMENT ≠ IMPLEMENTED ≠ RELEASE-PROVEN` (see IMPLEMENTATION-READY-FEATURES).
