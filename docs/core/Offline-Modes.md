# Offline Mode vs Connected Optional (P0)

## Offline Mode (پیش‌فرض / اجباری برای Core)

```text
NO NETWORK
NO REQUEST
NO REMOTE DEPENDENCY
NO LICENSE SERVER CHECK
```

ثبت تراکنش، وام، گزارش از ledger، valuation با قیمت کش/دستی — همه کار می‌کنند.

## Connected Optional Mode (opt-in)

- Price Update
- Version Check
- License Refresh / activation
- Import Provider online

Core **هرگز** برای عملکرد روزمره به شبکه وابسته نیست.
