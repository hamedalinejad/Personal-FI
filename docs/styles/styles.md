styles/ — استایل‌های سراسری
این پوشه برای استایل‌های عمومی، تم و تنظیمات Tailwind است.
ساختار پیشنهادی
Bashstyles/
├── globals.css              # استایل‌های سراسری و reset
├── fonts.css                # فونت‌های فارسی و لاتین
├── themes.css               # متغیرهای رنگ تم روشن/تیره
└── tailwind.css             # ورود Tailwind (در صورت نیاز)
مسئولیت‌ها

تعریف CSS Variables برای رنگ‌ها و فاصله‌ها
پشتیبانی از Dark Mode
فونت‌های فارسی (مثلاً Vazirmatn) و fallback
استایل‌های پایه body، scrollbar و ...

نکات

تا حد امکان از Utilityهای Tailwind استفاده شود.
رنگ‌های مالی (مثبت سبز، منفی قرمز) به صورت متغیر تعریف شوند.
خوانایی اعداد و مبالغ در UI اولویت داشته باشد.
