# Requirements R-012 … R-032

Status: **SPEC_LOCKED** unless marked IMPLEMENTED for a narrow slice.

## R-012 — Reversal specification (P0)

Every financial command must define:

```text
original rows | journal lines | cash legs | domain rows | snapshot rows
reversal command | reversal linkage (operationId → reverses_operation_id)
```

See `docs/core/requirements/REVERSAL-SPECS.md` for commands currently in runtime.

## R-013 — Rebuild determinism (P1)

```text
same ledger + engineVersions + asOf + valuation context → same output
```

No online provider call may affect historical reconstruction.

## R-014 — Recovery matrix as fixtures (P0/P1)

Scenarios (executable targets):

- crash before commit / after SQL before marker
- backup in progress / restore with attachments
- stale price / missing FX / unknown import
- license expiry / interrupted migration
- same operationId same command / different command
- rebuild after snapshot deletion

## R-015 — Offline browser (P1)

Local-first without network for registration, reports, backup/restore, loan, investment, accounting. Online only enhances price/FX/import/license.

## R-016 — Single-writer multi-tab (P1)

One writer per DB; `WRITER_REQUIRED`; version conflict; BroadcastChannel / navigator.locks.

## R-017 — Schema/migration unification (P0)

**IMPLEMENTED (Node path):** `openDb` → `ensureSchemaSync` → migration chain. No ad-hoc DDL on open.

## R-018 — Data preservation gate H (P0)

`no-field-loss = 0` across create → persist → load → export → import → migration → edition → backup/restore. Partial proof: operation envelope payload tests.

## R-019 — Identity collision tests (P0)

Golden cases: same-symbol stocks different venues; USDT TRC20 vs ERC20; same fund two accounts; same metal two platforms; same currency accounts scoped by role+currency.

**PARTIAL:** identity resolve unit/integration tests added under `src/core/domain/instrument/`.

## R-020 — Iran date semantics (P1)

Typed dates only: `createdAt`, `eventAt`, `businessDate`, `tradeDate`, `marketDate`, `settlementDate`, `dueDate`, `paymentDate`, `fetchedAt`.

## R-021 — Iran stock settlement policy (P1)

Versioned policy for expected/actual settlement, holidays, exceptions — not free same-day acceptance.

## R-022 — Corporate action execution (P1)

split, reverse split, bonus, rights, dividend, merger, delisting — one owning engine.

## R-023 — Funds price separation (P1)

NAV / transactionPrice / marketPrice / valuation price stored and queried separately.

## R-024 — Metals purity/fine-weight (P1)

Explicit gross/fine/purity/premium/delivery policy; `quantityMg` canonical.

## R-025 — Tax domain separation (P1/P2)

feeTax ≠ tax liability ≠ tax payment ≠ tax refund.

## R-026 — Import raw/provenance (P0)

Preserve raw payload, provider, schema, provider tx id, tx hash, log index, document, unknown fields, mapping, override.

## R-027 — Report source discipline (P1)

Every report declares source ledgers, engine, asOf, priceAsOf, fxAsOf, cash/liability scope, watermark.

## R-028 — Snapshot watermark (P1)

`sourceWatermark`, `calculatedAt`, `engineVersion`, `valuationContextHash`; rebuildable.

## R-029 — Accounting statements (P1)

GL, Trial Balance, Account Activity, BS, IS, CF, Opening Balance, Reconciliation.

## R-030 — Investment reports (P1)

holdings, cost basis, realized/unrealized P&L, price/FX effect, fees, external flows, wealth bridge — external flows ≠ P&L.

## R-031 — License capability matrix (P1)

Machine-readable edition/feature/UI/API/report read/write; **no license transition deletes data**.

## R-032 — Feature package contract generator (P2)

Manifest: public API, commands, queries, tables, modules, fixtures, status.
